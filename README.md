# Li-Fi-audio-transmission
# Overview
This project demonstrates a Li-Fi(Light Fidelity) wireless communication system designed for real-time audio transmission. By modulating light waves emitted from an LED, the system transmits analog signals wirelessly through free space to a receiver, which then demodulates the light back into audible sound using a speaker.

# Key Features
1. **Wireless and RF-free:** Uses visible light spectrum instead of radio frequencies(RF) making it immune to electromagnetic interference.
2. **Real-time Transmission:** Enable continuous, low-latency transmission of analog audio signals from an input source(like a smartphone or computer) to an output audio device.
3. **Cost-effective and Sustainable:** Built using readily available, low-cost electronic components.
4. **Line-of-Sight Demonstration:** Serves as a practical, hands-on model to understand the principles of optical wireless communication and data modulation
